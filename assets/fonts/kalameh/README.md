# فونت کلمه (Kalameh)

فونت «کلمه» یک فونت تجاری است و فایل‌هایش نمی‌تواند بدون لایسنس در مخزن قرار بگیرد.

پس از تهیه لایسنس از [فونت‌ایران](https://fontiran.com)، فایل‌های `woff2` را با این نام‌ها در همین پوشه قرار دهید تا به‌صورت خودکار فعال شود:

```
Kalameh-Regular.woff2
Kalameh-Medium.woff2
Kalameh-Bold.woff2
Kalameh-Black.woff2
```

تا قبل از آن، سایت به‌صورت خودکار از فونت جایگزین **وزیرمتن** (محلی، در `assets/fonts/vazirmatn/`) استفاده می‌کند.
