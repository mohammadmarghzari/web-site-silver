# SilvershopIR — وب‌سایت فروشگاه زیورآلات نقره اصفهان

وب‌سایت تک‌صفحه‌ای اسکرول‌محور با تم تیره؛ ساخته‌شده با HTML/CSS/JS خالص + GSAP و Lenis (همه کتابخانه‌ها **محلی** هستند و به CDN خارجی نیاز نیست).

## اجرای محلی

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000
```

حتماً از طریق HTTP باز کنید (نه `file://`).

## ساختار

```
index.html          صفحه اصلی (فارسی، RTL)
css/style.css       توکن‌های طراحی و استایل‌ها
js/app.js           موتور اسکرول (Lenis + GSAP) و رندر کنواس
js/vendor/          gsap / ScrollTrigger / lenis (محلی)
assets/fonts/       وزیرمتن (محلی) + جای فونت کلمه
assets/img/         تصاویر SVG جایگزین محصولات
frames/             محل فریم‌های ویدیوی واقعی (فعلاً خالی)
```

## جایگزینی ویدیوی واقعی

انیمیشن فعلی وسط صفحه (حلقه نقره) **جایگزین موقت** است. وقتی ویدیوی محصول آماده شد:

1. استخراج فریم‌ها (۱۵۰ تا ۳۰۰ فریم):
   ```bash
   ffmpeg -i video.mp4 -vf "fps=15,scale=1920:-1" -c:v libwebp -quality 80 "frames/frame_%04d.webp"
   ```
2. در `js/app.js` مقدار `FRAME_MODE` را به `"frames"` و `FRAME_COUNT` را به تعداد فریم‌ها تغییر دهید.

## فونت کلمه
